# LOMAS AI

A production-ready marketing website and enquiry workflow built with Next.js 14, TypeScript, Tailwind CSS, and App Router.

## Setup
```bash
npm install
npm run dev
```

## Verification
```bash
npm run lint
npm run build
```

## Routes
- `/`
- `/products`
- `/blogs`
- `/about-us`
- `/contact-us`
- `/api/enquiry`

## Folder Structure
```text
app/
components/
data/
lib/
public/
```

## Enquiry Providers
- `mock` for local UI verification
- `firebase` for Firestore submissions
- `mongodb` for API-based MongoDB submissions
